![Mods Configuration title](https://raw.githubusercontent.com/skyrim-aetherium/Aetherium/refs/heads/main/images/titles/aetherium_title_mods-configuration.png)Most mods relies on **Mod Configuration Menu (MCM)** for customization. In game, go to `System` > `Mod Configuration Menu (MCM)`. Some mods rely on other in game menu or configuration files

<details><summary>Further Configuration</summary>
  
### **Config Files**
Many mods can be manually configured from their `.ini` files usually located here : `\Skyrim Special Edition\Data\skse\plugins\` - Edit them at your own risk

### In game menus

[**Immersive Equipment Displays**](https://www.nexusmods.com/skyrimspecialedition/mods/62001)

- `Return` to configure **IED**

[**Community Shader**](https://www.nexusmods.com/skyrimspecialedition/mods/86492)

- `End` configuration menu
- `F10` real time performance

[**dMenu**](https://www.nexusmods.com/skyrimspecialedition/mods/97221)

- `Home` to open the menu
- For [**Wheeler**](https://www.nexusmods.com/skyrimspecialedition/mods/97345) customization
- For [**Compass Navigation Overhaul**](https://www.nexusmods.com/skyrimspecialedition/mods/74484) customization
</details>

<details><summary>🔆 Brightness & Lighting</summary>
  
You can change interior brightness from [**Lux**](https://www.nexusmods.com/skyrimspecialedition/mods/43158) (main) FOMOD - update accordingly [**Lux Via**](https://www.nexusmods.com/skyrimspecialedition/mods/63588) and [**Lux CS**](https://www.nexusmods.com/skyrimspecialedition/mods/153919) FOMODs.

Ultimately, [**Actually Brighter Lux Templates**](https://www.nexusmods.com/skyrimspecialedition/mods/136594) provides even brighter interiors.

Finaly, Community Shaders has an in-game menu (`F10`) in which you can find multiple lighting settings - **Screen Space GI IL** and **IL radius** are good ways of modifying interior lightings without breaking the general brightness balance.
</details>
